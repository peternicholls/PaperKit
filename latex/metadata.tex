\title{Color Journey Engine: A Perceptually-Uniform Palette Generation Specification}

\author{Peter Nicholls}

\date{\today}

% ==============================================================================
% Abstract
% ==============================================================================
% Note: Replace this placeholder with your actual abstract when ready
\newcommand{\abstracttext}{%
  This paper specifies the Color Journey Engine, a deterministic algorithm for generating perceptually coherent color palettes under explicit constraints from perceptual color science. Building on OKLab as a pragmatic Euclidean approximation to locally Riemannian perceptual geometry, the engine constructs color journeys as cubic Bézier paths through perceptual space, producing reproducible palettes from one to five anchor colors. A single anchor expansion mode generates controlled variations by moving along lightness and chromatic directions with channel weighting informed by temporal sensitivity asymmetries. The specification defines perceptual step constraints using just-noticeable difference thresholds, provides style parameters for temperature, intensity, and smoothness, and describes loop-closure strategies for extended sequences. A two layer gamut management strategy ensures valid sRGB output while preserving intended perceptual structure. The engine is defined as a pure function to guarantee repeatability across implementations, supporting palette generation for user interfaces, data visualization, and other procedural applications.
